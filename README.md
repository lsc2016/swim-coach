# 수영 코치

**물이 무서운** 성인이 혼자 수영을 배우기 위한 앱. **수영장 찾기**(어디로 갈까)와 **오늘의 수업**(가서 뭘 할까) 두 가지만 있습니다.

서버 없는 정적 웹앱이고, GitHub Pages에서 열립니다: **https://lsc2016.github.io/swim-coach/**

## 실행 방법 3줄

1. 휴대폰 Safari(또는 Chrome)로 **https://lsc2016.github.io/swim-coach/** 열기
2. 공유 버튼 → **홈 화면에 추가** → 이제 '수영 코치' 아이콘으로 앱처럼 열림
3. 한 번 열어 두면 탈의실처럼 인터넷이 안 되는 곳에서도 열림 (맥북 필요 없음)

맥북에서 md를 고친 뒤 push 전에 미리 보고 싶으면: `./run.sh` → http://localhost:8080

## 데이터가 어디에 있나

| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| 커리큘럼, 수영장 목록 | 저장소 `data/` 의 md | md를 고쳐서 `git push` → 1~2분 뒤 앱에 반영 (앱을 다시 열 때 새로 받음) |
| 내 연습 기록, 동네, 다니는 수영장 | **휴대폰 브라우저 안** | 앱에서 입력. 기록 화면의 **md로 내보내기**로 꺼내기 |
| 앱에서 고친 수영장 표 | 휴대폰 브라우저 안 | 수영장 화면의 **pools.md 내보내기** → `data/pools.md`를 바꿔서 push |

### 기록 내보내기 → 저장소에 남기기

1. 앱 → 기록 → **md로 내보내기** → `swim-log-날짜.zip` (안에 `2026-10-20.md`처럼 날짜별 md)
2. 아이폰이면 공유 시트에서 "파일에 저장" 또는 맥북으로 AirDrop → zip을 풀어서 md들을 `data/log/`에 넣기
3. `git add data/log && git commit -m "수영 기록" && git push`

저장소의 `data/log/`에 있는 기록도 앱이 읽습니다. 그래서 휴대폰 브라우저 데이터가 지워져도, 내보내서 push해 둔 날까지는 진도가 그대로 이어집니다.

> - 브라우저 저장은 지워질 수 있어요(브라우저 데이터 삭제, 오래 안 쓰면 iOS가 정리 등). 기록 화면 맨 위의 "마지막 내보내기: 날짜"를 보고 가끔 내보내 주세요.
> - 아이폰은 **Safari와 '홈 화면 앱'의 저장 공간이 따로**입니다. 홈 화면 앱으로만 쓰세요.
> - 이 저장소는 공개(public)라서 push한 기록 md도 공개됩니다. 동네·다니는 수영장은 휴대폰에만 있고 저장소에 올라가지 않습니다.

## md 파일 직접 고치는 법

`data/` 폴더를 Obsidian 보관함으로 열면 그대로 보입니다. 고친 뒤 push하면 앱에 반영됩니다.

| 파일 | 내용 | 고칠 때 지킬 것 |
|---|---|---|
| `data/pools.md` | 수영장 표 | **얕은 레인 수심**(예: `1.0m (3개 레인)`)과 **한가한 시간대**를 꼭 채워 주세요 — 얕은 순으로 정렬돼요. 표의 **열 이름은 그대로**. 칸 안에 `\|` 쓰지 않기. 자유수영 시간은 `평일 06:00-07:50, 12:00-12:50 / 토·일 09:00-11:50 / 월 휴장` 형식(요일 묶음은 `/`). 모르면 `확인 필요`. |
| `data/curriculum/*.md` | 수업 하나 = 파일 하나 | 위쪽 `---` 사이의 `순서`가 수업 순서, `단계이름`이 묶음 이름. 연습 메뉴 사이의 `> 🛑 **무서우면 여기서 멈추기** …` 줄이 멈추기 지점(바로 앞 카드에 표시). `## 연습 메뉴` 아래 `### 이름` + `- 몇 번:` / `- 어떻게:` 줄이 카드 한 장. 다른 `## 제목`(오늘의 목표, 준비, 잘 되고 있다는 신호, 잘못되고 있다는 신호, 흔한 실수와 고치는 법, 다음 수업으로 넘어가는 조건, 참고 영상)은 이름을 바꾸지 마세요. 새 수업은 파일을 복사해서 `id`와 `순서`만 바꾸면 됩니다. |
| `data/curriculum/보충-*.md` | 보충 수업 | `보충:` 값이 '힘들었던 점' 이름(물 마심 / 숨 참기 / 몸이 가라앉음 / 다리가 안 뜸)과 같아야 연결됩니다. |
| `data/log/2026-10-20.md` | 하루 기록 (내보낸 것) | 위쪽 `---` 사이가 앱이 읽는 부분(`수업`, `무서웠던 정도`, `다음: 넘어가기/반복/뒤로`, `힘들었던 점` 등). 아래 본문은 자유롭게. 같은 날짜 기록이 휴대폰에도 있으면 휴대폰 것이 우선입니다. |

## 수업 순서 (29개 + 보충 4개)

| 단계 | 수업 | 어디서 |
|---|---|---|
| 0단계 · 집에서 물과 친해지기 | 세면대에 얼굴 대기 → 샤워하며 물 맞기 → 대야에 코까지 | 집 |
| 1단계 · 물 적응 | 발만 담그고 앉기 → 벽 잡고 서기 → 어깨 → 턱 → 입 → 코 → 눈까지 → 벽 잡고 뜨기 → 음파 → 길게 내쉬기 | 수영장 얕은 쪽 |
| 자유형 25m까지 | 뜨기 → 미끄러지기 → 발차기 → 팔 → 옆 호흡 → 10m → 15m → 25m | 수영장 |
| 2단계 · 배영·평영 | 배영 2개, 평영 2개 | 수영장 |

모든 수업에는 **🛑 무서우면 여기서 멈추기** 지점이 있어요. 거기까지만 해도 그날 수업은 성공입니다.

## 선생님이 다음 수업을 정하는 규칙

- 다녀와서 맨 먼저 **오늘 무서웠던 정도**(전혀 / 조금 / 많이 / 못 들어감)를 묻습니다. **많이·못 들어감이면 다음 수업은 무조건 한 칸 뒤**로 갑니다(첫 수업이면 같은 수업을 멈추기 지점까지만).

- 전혀·조금이면 "다음 칸으로"와 "같은 수업, 조금만 더" 중에 고릅니다. 앱은 메뉴를 다 해 봤으면 "다음 칸", 아니면 "같은 수업"을 추천해요.
- 같은 수업을 다시 할 때는 순서를 그대로 두고, **지난번에 마지막으로 해 본 것 하나만 1분·5초·1번 더**.
- **힘들었던 점이 두 번 연속 같으면** 그걸 다루는 보충 수업을 먼저 끼워 넣습니다.

## 폴더

```
app/          화면 (HTML/JS/CSS, 오프라인 캐시, 홈 화면 아이콘)
data/         커리큘럼·수영장·내보낸 기록 (md)
build.py      app/ + data/*.md → _site/ (data.json으로 묶음)
run.sh        맥북 미리 보기
.github/workflows/pages.yml   push하면 자동 배포
```
