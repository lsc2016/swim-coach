# 수영 코치

혼자 수영을 배우는 성인 초보를 위한 앱. **수영장 찾기**(어디로 갈까)와 **오늘의 수업**(가서 뭘 할까) 두 가지만 있습니다.

## 실행 방법 3줄

1. 터미널에서 `cd ~/my_app/swim-coach && ./run.sh`
2. 맥북 브라우저: **http://localhost:8080**
3. 휴대폰(같은 와이파이): 화면에 찍힌 **https://…local:8443** 주소 (처음 한 번은 아래 '휴대폰 처음 설정')

끌 때는 터미널에서 `Ctrl+C`.

### 휴대폰 처음 설정 (한 번만)

탈의실처럼 인터넷이 안 되는 곳에서도 열리게 하려면 휴대폰이 이 맥을 믿도록 인증서를 한 번 설치해야 합니다.

**아이폰**
1. `./run.sh`를 켠 상태에서 Safari로 `http://<터미널에 찍힌 IP>:8080/ca.crt` 열기 → "허용"
2. 설정 앱 → 상단 "프로파일이 다운로드됨" → 설치
3. 설정 → 일반 → 정보 → 맨 아래 **인증서 신뢰 설정** → "Swim Coach Local CA" 켜기
4. Safari로 `https://<맥이름>.local:8443` 열기 → 공유 버튼 → **홈 화면에 추가**

**안드로이드**: 같은 주소로 `ca.crt`를 받아 설정 → 보안 → 인증서 설치(CA 인증서) → Chrome으로 https 주소 열고 메뉴 → 홈 화면에 추가.

집에서 한 번 열어 두면, 수영장에서는 인터넷 없이도 열립니다. 수영장에서 남긴 기록은 휴대폰에 보관됐다가 **집 와이파이에서 앱을 다시 열면** 맥북의 md 파일로 저장됩니다. (그때 맥북에서 `./run.sh`가 켜져 있어야 해요.)

> 인증서 없이 `http://<IP>:8080`으로 열어도 쓸 수는 있지만, 이 경우 오프라인으로는 안 열립니다.

## md 파일 직접 고치는 법

모든 데이터는 `data/` 폴더의 마크다운 파일입니다. Obsidian에서 `data` 폴더를 보관함으로 열면 그대로 보입니다. 고친 뒤 앱 화면을 다시 열면(또는 설정 → "md 파일 다시 불러오기") 반영됩니다.

| 파일 | 내용 | 고칠 때 지킬 것 |
|---|---|---|
| `data/pools.md` | 수영장 표 | 표의 **열 이름은 그대로**. 칸 안에 `\|` 쓰지 않기. 자유수영 시간은 `평일 06:00-07:50, 12:00-12:50 / 토·일 09:00-11:50 / 월 휴장` 형식(요일 묶음은 `/`). 모르면 `확인 필요`. '지도' 칸은 앱이 저장할 때 자동으로 다시 만듭니다. |
| `data/curriculum/*.md` | 수업 하나 = 파일 하나 | 위쪽 `---` 사이의 `순서`가 수업 순서. `## 연습 메뉴` 아래 `### 이름` + `- 몇 번:` / `- 어떻게:` 줄이 카드 한 장. 다른 `## 제목`(오늘의 목표, 준비, 잘 되고 있다는 신호, 잘못되고 있다는 신호, 흔한 실수와 고치는 법, 다음 수업으로 넘어가는 조건, 참고 영상)은 이름을 바꾸지 마세요. 새 수업은 파일을 복사해서 `id`와 `순서`만 바꾸면 됩니다. |
| `data/curriculum/보충-*.md` | 보충 수업 | `보충:` 값이 '힘들었던 점' 이름(물 마심 / 숨 참기 / 몸이 가라앉음 / 다리가 안 뜸)과 같아야 연결됩니다. |
| `data/log/2026-10-20.md` | 하루 기록 | 위쪽 `---` 사이가 앱이 읽는 부분(`수업`, `다음: 넘어가기/반복`, `힘들었던 점` 등). 아래 본문은 사람이 읽는 용도라 자유롭게 써도 됩니다. 기록 파일을 지우면 그날은 안 간 것으로 계산됩니다. |
| `data/profile.md` | 사는 동네, 다니는 수영장 | `수업 지정: "05"`처럼 쓰면 다음 수업을 직접 정할 수 있습니다. |

## 선생님이 다음 수업을 정하는 규칙

- "넘어가기"를 고르면 다음 수업, "반복"이면 같은 수업을 다시 하되 **지난번에 안 된 것부터, 횟수를 조금 늘려서** (다 됐는데 반복이면 순서를 바꿔서).
- 앱의 추천: 연습 메뉴를 다 체크하면 "넘어가기", 하나라도 안 됐으면 "반복". 최종 선택은 내가 합니다.
- **힘들었던 점이 두 번 연속 같으면** 그걸 다루는 보충 수업을 먼저 끼워 넣습니다.

## 폴더

```
run.sh        실행
server.py     md 파일 읽기/쓰기 + 화면 제공 (Python 기본 기능만 사용)
app/          화면 (오프라인 캐시 포함)
data/         ← 내 데이터 전부 (md)
certs/        휴대폰용 인증서 (자동 생성, git에 안 올라감)
```
